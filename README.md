# Aromar — Site de Velas Aromáticas

Projeto pessoal de desenvolvimento web criado para apresentar produtos de uma marca de velas aromáticas e facilitar o processo de pedidos.

## Sobre o projeto

A Aromar é uma aplicação web desenvolvida com Next.js, TypeScript e CSS, com auxílio de ferramentas de inteligência artificial na implementação.

O projeto foi idealizado para oferecer uma experiência visual atrativa, com catálogo de produtos, apresentação de fragrâncias e funcionalidades voltadas à personalização de pedidos.

## Tecnologias utilizadas

- Next.js
- React
- TypeScript
- CSS
- Netlify

## Funcionalidades

- Catálogo de velas aromáticas
- Apresentação de fragrâncias
- Seleção de produtos e quantidades
- Personalização de pedidos
- Integração com WhatsApp
